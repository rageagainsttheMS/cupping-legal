# Cupping - Coffee Rater: legal pages

The public Privacy Policy, Terms of Use and account-deletion page for the Cupping - Coffee Rater app,
hosted with GitHub Pages. The app's own code is in a separate private repository.

The source of these pages is the `docs-site/` folder in the app repository. To change them, edit them
there, copy `docs-site/*` into `site/` here, and push to `main`. The workflow in
`.github/workflows/pages.yml` publishes `site/` automatically.
